CalmTerraria - Terraria for screen reader users

What you need
- Terraria and tModLoader, both from Steam, and tModLoader started at least once.
- A screen reader running. NVDA is what it has been used with.
- Windows.

Installing
1. Close tModLoader if it is open.
2. Run install.cmd in this folder. It copies the mod in, switches it on, and
   switches the older Terraria Access mod off if you have it. It says what it did.
3. Start tModLoader. The title menu speaks: Single player, Join by address,
   New character, New world, Exit.

Keys
Nothing to set up. The first time it runs, the mod moves three of the game's
own keys out of its way and says so in the game's log:
- Auto select goes from Left Shift to F.
- Smart cursor goes from Left Control to V.
- Quick mana goes from J to G.
If you had Terraria Access, it also puts the mouse buttons back on the mouse.
Everything else the game binds stays as you have it.

The controls are in controls.md.

Footsteps
For footsteps that differ by what you walk on, also install the Terraria
Ambience mod (and its API mod) from the Steam Workshop. CalmTerraria makes
them loud enough to walk by. Without it there are none; everything else works.

Updating
Run install.cmd from the newer copy. Your characters, worlds and waypoints
are not touched.
